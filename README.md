# Currency Converter

Flutter-приложение для конвертации валют.

## Возможности

- ввод суммы для конвертации;
- выбор исходной и целевой валюты;
- обмен валют местами;
- получение актуального курса через Frankfurter API;
- показ результата конвертации;
- обработка ошибок ввода;
- история последних 5 конвертаций.

## Используемый API

Приложение получает курс валют через Frankfurter API:

https://api.frankfurter.dev
